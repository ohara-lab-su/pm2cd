# 装置プロトコル

[English](../../en/manual/protocol.html) | [日本語](../../ja/manual/protocol.html)

## 対象と出典

装置の一次資料はツジ電子「PM4C-06Aシリーズ 取扱説明書」改訂4（2022-04-15）です。対象シリーズにPM2C-06Aを含みます。ただしPM16C-16を同一機種として扱いません。

## 通信

メーカー資料ではLAN、RS-232C、GP-IBのコマンド体系が共通で、デリミタはCR+LF固定です。このPython実装の `Communication` はTCPとASCIIエンコーディング、CR+LFを使用します。

## 代表コマンド

| コマンド | 機能 |
|---|---|
| `REM` / `LOC` | リモート / ローカル切替 |
| `VER?` | ファームウェアバージョン |
| `PS?x` / `PSx±ddddddd` | 位置読み出し / プリセット |
| `ABSx±ddddddd` / `RELx±ddddddd` | 絶対 / 相対移動 |
| `SSTPx` / `ESTPx` | 減速停止 / 急停止 |
| `STS?` | 全体状態読み出し |
| `SETLS?x` / `SETLSx...` | リミットスイッチ設定 |
| `FL?x` / `BL?x` | ソフトリミット読み出し |

`x` は0～3を表すシリーズ共通表記ですが、**PM2CD Python実装の有効チャンネルは0と1のみ**です。コマンド表はメーカー資料の冒頭2～4ページ、詳細は通信コマンド解説にあります。

## 装置操作とPython APIの境界

`set_limit()` は `SETLS?x` で設定を読み、必要に応じてデジタルリミットを有効化してから設定コマンドと `FLx` / `BLx` を送信する設計です。利用者が生コマンドの手順を直接組み立てる必要はありません。
